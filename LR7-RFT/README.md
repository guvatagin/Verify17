# ЛР7. IBM Rational Functional Tester

Подготовлены сценарии для desktop-приложения заказа товара. В RFT необходимо создать Functional Test Project, настроить JRE и приложение, записать сценарий `AddOrder`, добавить verification point, связать `datapool.csv` и выполнить все итерации.

## Обязательная проверка

Проверять не только наличие строки в интерфейсе, но и запись в XML/БД. Скрипт должен читать хранилище и сравнивать номер заказа, количество и дату.

IBM RFT не включен в Linux-песочницу, поэтому фактический запуск и скриншоты должны быть получены в среде с установленным IBM RFT.
