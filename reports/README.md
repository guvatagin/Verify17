# Отчёты

Для каждой ЛР оформить: цель, среду и версии, постановку задания, ход выполнения, команды запуска, исходный код, результаты тестов, найденные дефекты, скриншоты/логи и вывод.

Отдельно указать ограничения ЛР7: IBM Rational Functional Tester требует внешнюю среду с установленным продуктом.
