# Отчёт по лабораторной работе №1
## Работа на GitHub

### Цель
Освоить совместную работу в GitHub, подготовить функциональную спецификацию, use-case диаграмму и выполнить black-box тестирование.

### Выполнено
В `LR1-GitHub` добавлены инструкция, спецификация калькулятора, PlantUML-диаграмма и таблица тест-кейсов. Описаны предусловия, постусловия, альтернативные сценарии и негативные проверки.

### Команды
```bash
git clone https://github.com/LvovAP/Chukotka.git
git switch -c student/<фамилия>
git add .
git commit -m "LR1: add specification"
git push
```

### Результат
Материалы спецификации находятся в `LR1-GitHub/specification.md`, диаграмма — в `use-case.puml`, тесты — в `black-box-cases.md`.

### Ограничение
Фактическая проверка приложения другой команды и создание Issues зависят от доступности приложения и репозитория команды. В репозитории подготовлен полный шаблон для фиксации таких результатов.
