# Отчёт по лабораторной работе №8
## Web-тестирование Selenium

### Выполнено
Подготовлены Selenium IDE сценарий и NUnit/Selenium WebDriver тест на C#. Тест открывает `/login`, вводит тестовые данные и проверяет сообщение об ошибке. Для динамических элементов используется явное ожидание.

### Запуск
Требуется локальное тестовое web-приложение на `http://localhost:8080`.

```bash
dotnet test LR8-Selenium/Selenium.Tests.csproj
```

### Проверяемые условия
- наличие формы входа;
- отображение ошибки неверного пароля;
- для успешного сценария — появление профиля и последующий logout;
- для операции сохранения — наличие результата в интерфейсе и в тестовом API/файле/БД.

### Ограничение
Selenium не включён в текущий CI, поскольку репозиторий не содержит тестового web-приложения на `localhost:8080`. Фактический прогон нужно выполнить после запуска такого приложения.
