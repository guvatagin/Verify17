# Отчёт по лабораторной работе №2
## Модульное тестирование Java с JUnit 5

### Среда
Java 17, Maven, JUnit Jupiter 5.10.2.

### Выполнено
Создан Maven-проект `LR2-JUnit`. Реализован `Calculator` с операциями сложения и деления. Тесты проверяют положительные и отрицательные значения, погрешность `double`, исключение при делении на ноль и ограничение времени выполнения.

### Запуск
```bash
cd LR2-JUnit
mvn clean test
```

### Результат
Проверка включена в GitHub Actions. Java job завершился успешно для коммита `cd31448`.

### Вывод
Модульные тесты отделены от production-кода и запускаются Maven без привязки к IDE.
