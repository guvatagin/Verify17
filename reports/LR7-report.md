# Отчёт по лабораторной работе №7
## Desktop-тестирование IBM Rational Functional Tester

### Выполнено
В `LR7-RFT` подготовлены описание сценария заказа, пример verification point и `datapool.csv` с несколькими наборами данных. Описана обязательная проверка постусловия: запись должна присутствовать не только в интерфейсе, но и в XML/БД.

### Порядок запуска в IBM RFT
1. Создать Functional Test Project.
2. Настроить desktop-приложение и совместимую JRE.
3. Записать сценарий заказа.
4. Добавить verification point на таблицу заказов.
5. Связать сценарий с `datapool.csv`.
6. Запустить все итерации и проверить хранилище.

### Ограничение
IBM Rational Functional Tester отсутствует в текущей Linux-песочнице. Поэтому фактический RFT-прогон, журнал и скриншоты не заявляются как выполненные; для завершения отчёта их нужно получить в среде с установленным RFT.
