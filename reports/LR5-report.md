# Отчёт по лабораторной работе №5
## Разработка через тестирование (TDD)

### Цель
Показать цикл Red–Green–Refactor на примере калькулятора.

### Выполнено
В `LR5-TDD` создан Maven-проект с тестами создания калькулятора, сложения, умножения и обработки деления на ноль. Production-логика отделена от тестов.

### Запуск
```bash
cd LR5-TDD
mvn clean test
```

### Результат
Maven-проверка входит в успешный Java job GitHub Actions для `cd31448`.

### Ограничение
Текущая ветка содержит рабочую TDD-реализацию, но исторические коммиты Red–Green–Refactor представлены не для каждого отдельного шага. Для полной демонстрации методологии следует дополнить историю последовательными коммитами тест → минимальный код → рефакторинг.
