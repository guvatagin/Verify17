# Функциональная спецификация калькулятора

## UC-01. Сложение

**Предусловие:** приложение запущено. Пользователь вводит два числа и нажимает «Сложить». **Постусловие:** результат отображается без изменения исходных операндов.

## UC-02. Деление

При ненулевом делителе отображается частное. При нулевом делителе выводится понятная ошибка, приложение продолжает работу.

## Негативные случаи

Пустое поле, нечисловой ввод, отрицательные числа, ноль, очень большие значения. Программа не должна завершаться необработанным исключением.
